# Code audit: November 2026

This is a full read of every source file in the repository (app, lib, public/lab, scripts, tests and docs), followed by a second pass over every changed line. Each finding is listed with its status.

## Security

| # | Finding | Status |
| --- | --- | --- |
| S1 | `next@16.3.4` had a critical `npm audit` advisory group, including image-optimizer RCE/SSRF and cache poisoning | **Fixed**: upgraded to 16.4.6 (`npm audit`: 0 vulnerabilities) |
| S2 | No security headers; `X-Powered-By: Next.js` was exposed | **Fixed**: CSP `frame-ancestors 'none'; object-src 'none'; base-uri 'self'`, nosniff, Referrer-Policy, Permissions-Policy (geolocation self only), HSTS, `poweredByHeader: false` |
| S3 | `/api/journey` does CPU work per request with no limit | **Fixed**: per-client token bucket on journey and graph (429 + `Retry-After`) |
| S4 | Upstream size check ran only after the whole body was buffered | **Fixed**: `Content-Length` is checked first; the post-read check stays |
| S5 | No `.gitignore` in the repository (the docs said there was one) | **Fixed** |
| S6 | Rate limiting keys on the first `X-Forwarded-For` value, which a client can spoof | Documented. Low impact: the bucket map is bounded, and the MTA calls are cached anyway |

## Bugs

| # | Finding | Status |
| --- | --- | --- |
| B1 | The decoder dropped a train dwelling at the platform (arrived, not yet departed), so it could not be boarded or shown | **Fixed** in the decoder, both search engines and the board ("Now") |
| B2 | Trip advisories included every alert on a line, even for stations the trip never touches (for example "4 skips Burnside Av" on a trip to 161 St) | **Fixed**: an alert is shown only if it is line-wide or names a station on the trip |
| B3 | Station alerts showed every station-specific alert on the station's lines | **Fixed**: labelled "This station" / "Line-wide"; other stations are collapsed |
| B4 | Alert line matching compared `7X` with `7` literally | **Fixed** with `baseRoute()` |
| B5 | Static map data expired on 2026-10-31 with no warning, and the import script failed if any station was added or renamed | **Fixed**: in-app warning, script regenerates `stations.json`, weekly refresh PR workflow. *The data itself still needs one refresh run; see below.* |
| B6 | "No connection found" gave no reason (Staten Island trips need a ferry; long trips exceed the 1-hour window) | **Fixed**: reason codes and a typical-time estimate |
| B7 | Planner made riders choose a platform; picking 161 St "4" ignored the B/D at the same station | **Fixed**: whole-complex search (`scope=complex`) |
| B8 | Lab "MTA feed inspector" fetched MTA directly from the browser, which CORS blocks | **Fixed**: raw bytes come through `/api/arrivals?format=protobuf`, still decoded in the browser. Added the SIR feed |
| B9 | Phone header overflowed by about 45 px once a nav link was added | **Fixed** (route-demo link hidden under 620 px; it is linked in the page) |
| B10 | Module-level caches could be duplicated across separately bundled routes | **Fixed**: shared on `globalThis` |
| B11 | Missing favicon request (404) | **Fixed**: brand icon, manifest, OG image |

Correction to the first review: "6 6" / "7 7" badges are **not** a bug. The second badge is the diamond-shaped express bullet, which matches MTA convention. Badges now also have accessible labels ("6 express").

## Features added

- RAPTOR planner with Pareto options and a "How we found this" panel (trains scanned, stop predictions checked, rounds, ms)
- `/algorithms`: BFS vs Dijkstra vs A* vs fewest-changes on the live graph, with a replay of each search
- Step-free trips from MTA elevator status; elevator panel with outage times and alternatives
- Countdown-accuracy tracker and display
- Destination labels ("L to 8 Av"), headsigns on the direction buttons
- Ctrl/⌘ + scroll and trackpad pinch zoom on the map

## Verification performed

- `npm test`: 53 tests passing. This includes 3,000 random-network comparisons of RAPTOR against the independent search, 500 A*-vs-Dijkstra optimality checks, and the original 8,670 lab oracle checks.
- `npm run build`: compiles and type-checks.
- A real MTA snapshot (all 8 feeds) recorded from the live site was replayed through a local mock of MTA's API. Every endpoint, the planner, the algorithms page and the lab inspector were checked end to end in headless Chrome at desktop and phone widths, with no console errors.
- Not verified here: the live MTA endpoints from this build environment (outbound access is blocked), the protobuf alert feed under the mock, and Hostinger deployment. Run `npm run test:live` after deploying.
