Simulation only. These are search steps, not travel directions or live train movements.

Learn more about the method

This uses Dijkstra’s algorithm, a method named after computer scientist Edsger Dijkstra. It finds the route with the lowest total in this example network.

The app checks the lowest-total option first, then compares its connections. It remembers the subway line used to reach each station so it can account for train changes. The same station may appear more than once when different lines are compared.

All travel times and delays here are examples. Each train change adds four simulated minutes. Your preference can add extra comparison points to favor fewer changes; those points are not extra travel minutes.

THE PROJECT IN SIX PARTS

How the route lab makes a choice

01

The question

If a line slows down or a station closes, which example route works best? The answer can change when you prefer fewer train changes.

02

The example network

The map connects 17 selected stations with example travel times. The app remembers which line reaches each station so it can include the time needed to change trains.

03

How options are compared

The comparison adds example ride times, delays, and four minutes for each train change. Preferring fewer changes adds comparison points, but does not add minutes to the displayed journey time.

04

The method behind the choice

Dijkstra’s algorithm is a way to find the lowest-total route through a network. It compares the most promising option first and keeps track of the connections that lead to the best route. The walkthrough lets you follow those comparisons.

05

What this lab leaves out

This simulation does not include train waiting times, current schedules, actual service directions, or real elevator status. The step-free option checks every station in the example route. It cannot confirm that a real trip is accessible.

06

The next iteration — now live

The ideas here now run on real data. The trip planner uses RAPTOR over live MTA predictions with official transfers and elevator status, and the algorithms page compares BFS, Dijkstra and A* on a graph of the whole subway learned from the trains running right now.
